`Geist-Medium.woff2`) qui ne sont plus présents : son rendu n’est donc pas garanti.

aussi conservées dans les tags Git du dépôt :

`v6-fluide`, `v7-sans-parallaxe`, `v8-categories`, `v9-cote-fixe`,

`index.html`.
